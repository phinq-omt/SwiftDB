Support

Report a problem or ask a question. The application source is not in this repository.

Help, bugs, and ideas

Open an issue in the SwiftDB issue tracker.

Reporting a connection problem

Include the SwiftDB version, macOS version, database engine, and the error text with secrets removed. Do not include passwords, private keys, production data, or a full connection string.

Help in the app

Choose Help → SwiftDB Help for usage and privacy notes. Install and update steps are on the install page.
