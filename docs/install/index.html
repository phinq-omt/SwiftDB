Install

SwiftDB is a direct download for macOS. It is not distributed through TestFlight or the Mac App Store.

Version 1.0.2. Requires macOS 14 Sonoma or later.

Download SwiftDB.dmg

Install the app

  1. Open the downloaded SwiftDB.dmg.
  2. Drag SwiftDB onto the Applications folder.
  3. Eject the disk image and open SwiftDB from Applications.

The app is signed with a Developer ID and notarized by Apple. The first launch may say that Apple checked the app for malicious software. Choose Open. You do not need to change Gatekeeper settings.

Updates

An installed copy checks for a newer build on its own. You can also choose SwiftDB → Check for Updates… in the menu bar. When a newer build is published, Sparkle downloads it and asks you to relaunch.

You can also download SwiftDB.dmg again. That address always serves the latest published build. Replace the copy in Applications, then open the app.

If the download is missing

The file appears after the first release is published. If the link fails before that, check this page again later.
